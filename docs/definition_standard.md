# BKM - Definition Writing Standard

## Version 1.0
**Last Updated:** July 2026
**Status:** Production Standard

## 1. Overview

This document establishes the writing standard for all definitions in the BKM Knowledge Base. Consistent definition writing ensures clarity, discoverability, and quality across the entire knowledge graph.

## 2. Definition Types

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          DEFINITION TYPES                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Type              │ Purpose              │ Max Length             │
    │   ─────────────────┼──────────────────────┼─────────────────────────│
    │   Quick Summary     │ One-line overview    │ 150 characters          │
    │   Short Definition  │ Brief explanation    │ 150 characters          │
    │   Full Definition  │ Comprehensive guide  │ 2000 characters        │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘
```

### 2.1 Quick Summary

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          QUICK SUMMARY                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose: One-sentence overview for search results and quick reference
    
    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Single sentence or fragment
    • No period required at end
    • No markdown formatting
    • Action-oriented when possible
    • Direct and concise
    
    Example:
    ─────────────────────────────────────────────────────────────────────────
    
    Good:
    "A shot using backspin to bring the cue ball back toward you"
    
    Acceptable:
    "Draw shot is a technique using backspin to reverse cue ball direction"
    
    Avoid:
    "The draw shot, also known by many names in various contexts, represents 
    a fundamental technique..." (too long, verbose)
```

### 2.2 Short Definition

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         SHORT DEFINITION                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose: Concise explanation for cards and previews
    
    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • 1-3 sentences
    • Basic markdown allowed (bold, italic)
    • No headings or lists
    • Self-contained explanation
    • Plain language focus
    
    Structure:
    ─────────────────────────────────────────────────────────────────────────
    [Technique Name] is [what it is]. It [primary action/result].
    
    Example:
    ─────────────────────────────────────────────────────────────────────────
    
    Good:
    "A **draw shot** is a technique using backspin. The cue ball reverses 
    direction after contacting the object ball."

    Acceptable:
    "Draw shot: A backspin technique that brings the cue ball back toward 
    the player after contact."

    Avoid:
    "A draw shot is a type of cue ball control shot that..." (fragment)
```

### 2.3 Full Definition

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          FULL DEFINITION                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose: Comprehensive explanation for detailed learning
    
    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Multiple paragraphs
    • Full markdown support
    • Can include headings (H2-H4)
    • Can include bullet lists
    • Can include blockquotes
    • Rich formatting encouraged
    
    Structure:
    ─────────────────────────────────────────────────────────────────────────
    Paragraph 1: What it is (definition)
    Paragraph 2: How it works (mechanism)
    Paragraph 3: Why it matters (application)
    Additional sections as needed
    
    Example:
    ─────────────────────────────────────────────────────────────────────────
    
    ## Draw Shot

    A **draw shot** (also called a screw shot or pull shot) is a fundamental 
    cue ball control technique executed by striking the cue ball below center.

    The backspin causes the cue ball to reverse direction after contacting 
    an object ball, traveling back toward or past the player.

    ### When to Use

    - Position play behind obstacles
    - Narrow gap navigation
    - Combo and carom setups
    - Long distance control

    > "The draw shot is essential for position play at every level."
    > — Standard Pool Instruction
```

```
    ─────────────────────────────────────────────────────────────────────────

      (Expert-level brevity)
```

## 4. Writing Style

### 4.1 Voice and Tone

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            VOICE AND TONE                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    Voice:
    ─────────────────────────────────────────────────────────────────────────
    Use second person ("you") for instructions and guidance:
    
    ✓ "Hold the cue with a relaxed grip"
    ✗ "The player should hold the cue with a relaxed grip"
    
    Use third person for definitions and explanations:
    
    ✓ "A draw shot uses backspin to reverse cue ball direction"
    ✓ "Draw shots require below-center contact"
    ✗ "You use draw shots when you need backspin"
    
    Tone:
    ─────────────────────────────────────────────────────────────────────────
    • Professional but accessible
    • Clear and direct
    • Confident (avoid hedging words)
    • Supportive and encouraging
    
    Recommended:
    ─────────────────────────────────────────────────────────────────────────
    ✓ "This technique requires practice"
    ✓ "Master this technique for better position play"
    ✗ "This technique might be somewhat difficult"
    ✗ "One could potentially try this technique"
    
    Clarity:
    ─────────────────────────────────────────────────────────────────────────
    ✓ "Draw the cue back smoothly"
    ✗ "Employ a smooth drawing motion with the implement"
```

### 4.2 Sentence Structure

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          SENTENCE STRUCTURE                                  │
└─────────────────────────────────────────────────────────────────────────────┘

    Average Sentence Length:
    ─────────────────────────────────────────────────────────────────────────
    • Target: 15-20 words
    • Acceptable: 10-25 words
    • Maximum: 35 words
    
    Word Count Examples:
    ─────────────────────────────────────────────────────────────────────────
    Good (18 words):
    "A draw shot uses backspin to reverse the cue ball's direction 
    after it contacts the object ball."
    
    Acceptable (25 words):
    "The draw shot, also known as a screw or pull shot, creates backspin 
    that causes the cue ball to travel backward after contacting 
    the object ball."
    
    Too Long (42 words):
    ✗ "The draw shot which is also known by several other names 
    including screw shot and pull shot is a fundamental technique 
    in pool that creates backspin which causes the cue ball to reverse 
    direction after contacting the object ball."
    
    Fragment Tolerance:
    ─────────────────────────────────────────────────────────────────────────
    Short definitions may use sentence fragments:
    
    ✓ "Backspin technique. Reverses cue ball direction after contact."
    
    Full definitions should use complete sentences:
    
    ✓ "The backspin causes friction with the cloth, reversing direction."
```

### 4.3 Active vs Passive Voice

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ACTIVE VS PASSIVE                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    Prefer Active Voice:
    ─────────────────────────────────────────────────────────────────────────
    ✓ "Strike the cue ball below center"
    ✗ "The cue ball should be struck below center"
    
    ✓ "Backspin causes the ball to reverse"
    ✗ "The ball is caused to reverse by backspin"
    
    Acceptable Passive (when actor is unknown or irrelevant):
    ─────────────────────────────────────────────────────────────────────────
    ✓ "The technique was developed in the early 1900s"
    ✓ "These principles are taught in most pool schools"
    
    Avoid Passive When:
    ─────────────────────────────────────────────────────────────────────────
    ✗ "Your cue tip should be placed below center" (directive)
      → "Place your cue tip below center"
    
    ✗ "The ball needs to be struck firmly" (instruction)
      → "Strike the ball firmly"
```

## 5. Terminology Standards

### 5.1 Technical Terminology

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         TECHNICAL TERMINOLOGY                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    Use Standard Pool Terminology:
    ─────────────────────────────────────────────────────────────────────────
    ✓ cue ball (not "white ball")
    ✓ object ball (not "target ball" or "colored ball")
    ✓ pocket (not "hole")
    ✓ cue tip (not "tip of the stick")
    ✓ bridge (not "rest")
    ✓ follow through (not "follow through stroke")
    
    BKM Standard Terms:
    ─────────────────────────────────────────────────────────────────────────
    ✓ cue ball (bóng cơ)
    ✓ object ball (bóng mục tiêu)
    ✓ pocket (ló)
    ✓ shot (đòn đánh)
    ✓ technique (kỹ thuật)
    ✓ draw shot (đường cắt đít)
    ✓ follow shot (đường theo)
    ✓ stop shot (đường dừng)
    
    Jargon Acceptance:
    ─────────────────────────────────────────────────────────────────────────
    Beginner content: Avoid or explain
    Intermediate content: Use with context
    Advanced content: Standard usage
    Professional content: Full technical terminology
```

### 5.2 Bilingual Terminology

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       BILINGUAL TERMINOLOGY                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    First Use Format:
    ─────────────────────────────────────────────────────────────────────────
    English term (Vietnamese translation):
    
    ✓ "A draw shot (đường cắt đít) uses backspin..."
    ✓ "The cue ball (bóng cơ) should be struck below center..."
    
    Established Terms:
    ─────────────────────────────────────────────────────────────────────────
    When the term is well-established in both languages:
    
    ✓ "Draw shot (đường cắt đít)"
    ✓ "English (kỹ thuật đánh xoáy)"
    ✓ "Bridge (tay trụ)"
    
    When Vietnamese Has No Direct Equivalent:
    ─────────────────────────────────────────────────────────────────────────
    Use English term with brief explanation:
    
    ✓ "english (side spin applied to the cue ball)"
    ✓ "scratch (pocket the cue ball illegally)"
    
    Loanwords:
    ─────────────────────────────────────────────────────────────────────────
    Acceptable when widely used:
    
    ✓ "break (đánh phá)"
    ✓ "scratch (ghiều)"
    ✓ "safety (đánh an toàn)"
```

### 5.3 Terminology Consistency

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        TERMINOLOGY CONSISTENCY                                │
└─────────────────────────────────────────────────────────────────────────────┘

    Use a Single Term Per Concept:
    ─────────────────────────────────────────────────────────────────────────
    ✓ "Use the draw shot for position control"
    ✓ "The draw shot provides excellent position control"
    ✗ "Use the draw/screw/pull shot interchangeably"
    
    Standard Variations:
    ─────────────────────────────────────────────────────────────────────────
    If multiple names exist, list alternatives in aliases:
    
    Short Definition: Use primary name
    Full Definition: Note alternatives once
    
    ✓ "A draw shot (also called screw shot or pull shot)"
    
    Cross-Reference Consistency:
    ─────────────────────────────────────────────────────────────────────────
    When linking to related terms:
    
    ✓ "See also: Follow Shot"
    ✓ "Compare with: Stop Shot"
    ✓ "Learn next: English with Draw"
```

## 6. Grammar Rules

### 6.1 Punctuation

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            PUNCTUATION                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    Periods:
    ─────────────────────────────────────────────────────────────────────────
    • Short definitions: Optional at end
    • Full definitions: Use periods
    • Quick summaries: No period needed
    
    Commas:
    ─────────────────────────────────────────────────────────────────────────
    • Use Oxford comma in lists of 3+
    ✓ "Draw, follow, and stop shots"
    ✗ "Draw, follow and stop shots"
    
    Colons and Semicolons:
    ─────────────────────────────────────────────────────────────────────────
    • Colons: Introduce lists or explanations
    ✓ "Three key elements: power, accuracy, position"
    
    • Semicolons: Separate complex list items
    ✓ "Stance; bridge; stroke"
    
    Quotation Marks:
    ─────────────────────────────────────────────────────────────────────────
    • Use double quotes for direct quotes
    ✓ '"The draw is essential," says the champion.'
    
    • Use single quotes for terms being defined
    ✓ 'The "english" refers to side spin.'
    
    Dashes:
    ─────────────────────────────────────────────────────────────────────────
    • Em dash (—): Set off parenthetical information
    ✓ "The draw shot—essential for position play—requires..."
    
    • En dash (–): Ranges or connections
    ✓ "Levels 1–5 include fundamentals"
    
    Hyphens:
    ─────────────────────────────────────────────────────────────────────────
    • Compound modifiers: Hyphenate
    ✓ "backspin-producing motion"
    ✓ "follow-through direction"
    
    • Prefix combinations: Generally no hyphen
    ✓ "non-essential"
    ✓ "semi-professional"
```

### 6.2 Capitalization

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           CAPITALIZATION                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    Title Case (Article Names):
    ─────────────────────────────────────────────────────────────────────────
    ✓ "Draw Shot"
    ✓ "Stop Shot"
    ✓ "English with Draw"
    
    Sentence Case (Definition Text):
    ─────────────────────────────────────────────────────────────────────────
    ✓ "A draw shot uses backspin."
    ✓ "The technique requires below-center contact."
    
    Proper Nouns:
    ─────────────────────────────────────────────────────────────────────────
    ✓ "Billiards Congress of America (BCA)"
    ✓ "World Pool-Billiard Association (WPA)"
    ✓ "Vietnam Pool Association"
    
    Equipment Names:
    ─────────────────────────────────────────────────────────────────────────
    ✓ "Wilson•R MIT® leather tip"
    ✓ "Predator 314² shaft"
    
    Avoid Unnecessary Capitalization:
    ─────────────────────────────────────────────────────────────────────────
    ✗ "The Cue Ball should be struck firmly"
    ✓ "The cue ball should be struck firmly"
    
    ✗ "Learn the Draw Shot technique"
    ✓ "Learn the draw shot technique"
```

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          NUMBERS                                             │
└─────────────────────────────────────────────────────────────────────────────┘

    ✓ "3/8 tip below center"
```

```
┌─────────────────────────────────────────────────────────────────────────────┐

    ─────────────────────────────────────────────────────────────────────────
```

## 7. Formatting Rules

### 7.1 Markdown Usage

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         MARKDOWN USAGE                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    Headings:
    ─────────────────────────────────────────────────────────────────────────
    Quick Summary: No headings
    Short Definition: Bold, italic only
    Full Definition: H2, H3, H4 allowed
    
    ✓ ## Definition
    ✓ ### Mechanics
    ✓ #### Advanced Mechanics
    
    ✗ H1 (reserved for article title)
    ✗ More than 3 heading levels
    
    Bold and Italic:
    ─────────────────────────────────────────────────────────────────────────
    Bold for: Key terms, critical information
    ✓ "**Draw shot** uses backspin"
    ✓ "Always maintain **straight follow-through**"
    
    Italic for: Emphasis, technical terms in context
    ✓ "The *english* refers to spin"
    ✓ "Mastery requires *dedicated practice*"
    
    Lists:
    ─────────────────────────────────────────────────────────────────────────
    Bullet lists: Unordered items
    ✓ "Use draw shot when:
       - Position control is needed
       - Narrow gaps exist
       - Long distances required"
    
    Numbered lists: Sequential steps
    ✓ "Follow these steps:
       1. Aim below center
       2. Accelerate through
       3. Follow through"
    
    Tables:
    ─────────────────────────────────────────────────────────────────────────
    Use for comparisons and structured data:
    
    ✓ | Shot Type | Spin | When to Use |
      |-----------|------|-------------|
      | Draw | Back | Position play |
      | Follow | Top | Forward control |
    
    Blockquotes:
    ─────────────────────────────────────────────────────────────────────────
    Use for expert quotes and callouts:
    
    ✓ "> 'The draw is fundamental.' — Pro Instruction"
    
    Code:
    ─────────────────────────────────────────────────────────────────────────
    Technical terms in context:
    
    ✓ "Use `below-center` contact"
    ✓ "Tip placement: `1/2 tip below center`"
```

### 7.2 Structure Patterns

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         STRUCTURE PATTERNS                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    Definition Opening Pattern:
    ─────────────────────────────────────────────────────────────────────────
    [Term] is [what it is]. [Key characteristic].
    
    Examples:
    ✓ "A draw shot is a technique using backspin. It reverses cue ball 
       direction after contact."
    
    ✓ "Draw shot (đường cắt đít) is a control technique using 
       backspin to reverse the cue ball's travel."
    
    Mechanism Explanation Pattern:
    ─────────────────────────────────────────────────────────────────────────
    When [action], then [result].
    
    Examples:
    ✓ "When the cue tip strikes below center, backspin is applied. 
       This causes the ball to reverse after contact."
    
    ✓ "Shaft acceleration creates spin. The spin determines 
       ball behavior after impact."
    
    Step Sequence Pattern:
    ─────────────────────────────────────────────────────────────────────────
    Use numbered lists for sequences:
    
    1. First action
    2. Second action  
    3. Result
    
    Comparison Pattern:
    ─────────────────────────────────────────────────────────────────────────
    Use tables for side-by-side comparison:
    
    | Feature | Draw Shot | Follow Shot |
    |---------|-----------|-------------|
    | Spin | Back | Top |
    | Direction | Reverses | Forward |
    
    Contrast Pattern:
    ─────────────────────────────────────────────────────────────────────────
    Unlike [comparison], [term] [characteristic].
    
    ✓ "Unlike a follow shot, a draw shot reverses direction."
    ✓ "Unlike stop shots, draw shots require backspin."
```

### 7.3 Visual Hierarchy

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        VISUAL HIERARCHY                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    Full Definition Structure:
    ─────────────────────────────────────────────────────────────────────────
    
    ## [Term Name] (H2)
    
    Opening paragraph - what it is
    
    ### What It Is (H3)
    - Definition paragraph
    - Key characteristics
    
    ### How It Works (H3)
    - Mechanism explanation
    - Cause-effect description
    
    ### Key Principles (H3)
    - Bulleted list of 3-5 principles
    - Each with brief explanation
    
    ### When to Use (H3)
    - Bulleted or numbered list
    - Practical application
    
    ### Common Mistakes (H3)
    - Numbered list
    - Each with correction
    
    #### Mistake 1 (H4)
    Description and fix
    
    #### Mistake 2 (H4)
    Description and fix
    
    ### Pro Tips (H3)
    - Bulleted expert insights
    - Optional blockquote
    
    ─────────────────────────────────────────────────────────────────────────
    
    Density Guidelines:
    ─────────────────────────────────────────────────────────────────────────
    • No heading should have less than 2 sentences
    • Mix paragraph and list content
    • Break up long paragraphs (3-4 sentences max)
    • Use whitespace for readability
```

## 8. Beginner-Friendly Writing

### 8.1 Accessibility Levels

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ACCESSIBILITY LEVELS                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    Level 1 - Beginner (All Users):
    ─────────────────────────────────────────────────────────────────────────
    • Short sentences (10-15 words)
    • Common vocabulary
    • No jargon without explanation
    • Concrete examples
    • Step-by-step guidance
    
    Example:
    "A draw shot makes the cue ball spin backward. When you hit the ball 
    below center, it will come back toward you after hitting another ball."
    
    Level 2 - Intermediate:
    ─────────────────────────────────────────────────────────────────────────
    • Moderate sentence length
    • Some technical terms
    • Comparative explanations
    • Strategic context
    
    Example:
    "A draw shot applies backspin through below-center contact. Unlike 
    stop shots, draw causes the cue ball to reverse direction, essential 
    for position play behind obstacles."
    
    Level 3 - Advanced:
    ─────────────────────────────────────────────────────────────────────────
    • Technical vocabulary acceptable
    • Complex mechanisms explained
    • Strategic and tactical depth
    • Performance considerations
    
    Example:
    "Draw shot execution requires precise below-center tip placement 
    (typically ⅜ to ½ tip below center). The ratio of spin to forward 
    momentum determines rebound characteristics off object balls."
    
    Level 4 - Professional:
    ─────────────────────────────────────────────────────────────────────────
    • Full technical terminology
    • Elite-level nuances
    • Tournament context
    • Advanced physics
    
    Example:
    "Elite-level draw application involves spin transfer coefficients 
    and elastic collision dynamics. The optimal tip offset varies with 
    distance, cloth speed, and ball condition, requiring real-time 
    adjustment based on table conditions."
```

### 8.2 Explaining Technical Terms

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       EXPLAINING TECHNICAL TERMS                              │
└─────────────────────────────────────────────────────────────────────────────┘

    Techniques for Explanation:
    ─────────────────────────────────────────────────────────────────────────
    
    Parenthetical:
    ✓ "backspin (lực ngược)"
    ✓ "english (side spin on the cue ball)"
    
    Appositive:
    ✓ "backspin, the rotation that causes reverse ball movement"
    
    Brief Clause:
    ✓ "Draw shot, a technique using backspin to reverse direction"
    
    Comparison:
    ✓ "Unlike top spin which drives the ball forward, backspin reverses it"
    
    Example Integration:
    ✓ "The cue ball will 'draw back' — come back toward you — after 
       the shot."
    
    Definition Integration:
    ✓ "English refers to spin applied to the sides of the cue ball, 
       affecting its rebound angles."
```

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          QUALITY CHECKLIST                                   │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
    direction after contacting an object ball."
    
    Full Definition (Good):
    ─────────────────────────────────────────────────────────────────────────
    ## Draw Shot

    A **draw shot** (also called a screw shot or pull shot) is a fundamental 
    cue ball control technique that creates backspin, causing the cue ball 
    to reverse direction after contacting an object ball.

    ### How It Works

    When the cue tip strikes below center:

    1. Backspin is applied to the cue ball
    2. The ball slides forward initially
    3. Contact with the object ball transfers some energy
    4. Remaining backspin and cloth friction reverse the cue ball

    ### When to Use

    - Position play behind obstacles
    - Narrow gap navigation
    - Long distance control
    - Combo setups

    ### Common Mistakes

    1. **Scooping** — Lifting the cue instead of following through
    2. **Too much power** — Causes the ball to jump or miscue
    3. **Wrong contact point** — Hitting too far below causes miscues
```
