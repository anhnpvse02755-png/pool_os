**Last Updated:** July 2026

## 1. Overview

This document defines the standard for all examples used throughout the BKM Knowledge Base. Examples bring concepts to life, bridge theory and practice, and help learners understand how techniques apply in real situations.

## 4. Practical Example Standard

### 4.1 Definition

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          PRACTICAL EXAMPLE                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose: Demonstrate core application of the concept
    
    When to Use: Every technical term or technique article
    Placement: Within the Definition or Detailed Content section
    Frequency: Minimum 1 per article, recommended 2-3
    
    ─────────────────────────────────────────────────────────────────────────
    
    What Makes It "Practical":
    ─────────────────────────────────────────────────────────────────────────
    • Real-world application scenario
    • Specific ball positions
    • Actionable technique application
    • Clear cause and effect
    • Transferable to reader's own play
```

### 4.2 Structure

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      PRACTICAL EXAMPLE STRUCTURE                             │
└─────────────────────────────────────────────────────────────────────────────┘

    Required Sections:
    ─────────────────────────────────────────────────────────────────────────
    
    ### 1. Context (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Situation description
    
    Format: 2-4 sentences
    Content: Where, why, what balls are involved
    
    Example:
    "You're playing 8-ball and need to pocket the 3-ball in the corner 
    pocket. However, the cue ball is positioned behind the 5-ball, 
    blocking a direct shot."
    
    ### 2. Problem (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    What makes this challenging
    
    Format: 1-3 sentences
    Content: The obstacle or difficulty
    
    Example:
    "A straight-on shot is impossible. The 5-ball blocks the direct 
    line to the 3-ball."
    
    ### 3. Solution (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    How the technique solves it
    
    Format: 2-5 sentences
    Content: Step-by-step application
    
    Example:
    "You use a draw shot to curve the cue ball around the 5-ball. 
    Strike the cue ball ½ tip below center with medium acceleration. 
    The backspin causes the cue ball to travel right, contact the 
    3-ball, and then draw back toward the middle of the table."
    
    ### 4. Outcome (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    The result achieved
    
    Format: 1-3 sentences
    Content: What happened
    
    Example:
    "The 3-ball pockets cleanly in the corner pocket. The draw 
    brings the cue ball into perfect position for your next shot."
    
    ### 5. Learning Point (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Key takeaway
    
    Format: 1-2 sentences
    Content: Transferable insight
    
    Example:
    "Draw shot lets you navigate around obstacles while maintaining 
    control of cue ball position for position play."
```

### 4.3 Formatting

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       PRACTICAL EXAMPLE FORMATTING                            │
└─────────────────────────────────────────────────────────────────────────────┘

    Markdown Structure:
    ─────────────────────────────────────────────────────────────────────────

    ### Practical Example

    **Context:**
    [2-4 sentence description of the situation]

    **Problem:**
    [1-3 sentence description of the challenge]

    **Solution:**
    [2-5 sentence step-by-step application]

    **Outcome:**
    [1-3 sentence description of the result]

    **Learning Point:**
    [1-2 sentence takeaway]

    ─────────────────────────────────────────────────────────────────────────

    Visual Aids (Optional):
    ─────────────────────────────────────────────────────────────────────────
    • Table diagram for ball positions
    • ASCII art for layouts
    • Image reference for complex scenarios
    • Video timestamp for dynamic examples
```

## 5. Match Example Standard

### 5.1 Definition

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          MATCH EXAMPLE                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose: Show technique in competition context
    
    When to Use: Advanced and professional level articles
    Placement: Related Terms or Professional Tips section
    Frequency: 1-2 per relevant article
    
    ─────────────────────────────────────────────────────────────────────────
    
    What Makes It a "Match Example":
    ─────────────────────────────────────────────────────────────────────────
    • Tournament or match scenario
    • Strategic decision-making
    • Pressure context
    • Professional execution
    • Outcome impact on match
```

### 5.2 Structure

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        MATCH EXAMPLE STRUCTURE                               │
└─────────────────────────────────────────────────────────────────────────────┘

    Required Sections:
    ─────────────────────────────────────────────────────────────────────────
    
    ### 1. Match Context (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Tournament situation
    
    Format: 3-5 sentences
    Content: Event, score, stakes
    
    Example:
    "2019 WPA World Championship, Quarterfinal match. Shane Warne 
    leading 4-3 in a race to 9. Warne is down to the 8-ball in 
    the bottom corner with multiple balls remaining."
    
    ### 2. Table Situation (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Ball positions and layout
    
    Format: 2-4 sentences + optional diagram
    Content: Exact positions, obstacles
    
    Example:
    "The 8-ball sits 6 inches from the bottom-left corner pocket. 
    The cue ball is behind the 2-ball and 5-ball cluster near the 
    side pocket. The match is on the line."
    
    ### 3. Decision (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    What the player chose
    
    Format: 2-4 sentences
    Content: Why this technique was chosen
    
    Example:
    "Warne selected a controlled draw shot to navigate the cluster 
    and softly tap the 8-ball into the corner. A standard shot 
    would leave him safe with no follow-up. The draw gives him 
    position on the 2-ball if he makes the shot, or a safety if 
    he doesn't."
    
    ### 4. Execution (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    How it was performed
    
    Format: 2-4 sentences
    Content: Key technique elements
    
    Example:
    "He placed his tip ½ below center, used a smooth acceleration 
    through the ball, and followed through level. The draw brought 
    his cue ball back to center table regardless of outcome."
    
    ### 5. Result (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    What happened
    
    Format: 1-3 sentences
    Content: Immediate result
    
    Example:
    "The 8-ball dropped cleanly. Warne ran the remaining balls, 
    winning the match 5-3 and advancing to the semifinals."
    
    ### 6. Analysis (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Why this matters
    
    Format: 2-3 sentences
    Content: Strategic and technical insight
    
    Example:
    "This demonstrates the dual-purpose nature of controlled draw. 
    Even if the shot missed, his position strategy gave him a 
    fallback safety. Professional players always consider both 
    making and missing outcomes."
```

### 5.3 Formatting

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         MATCH EXAMPLE FORMATTING                              │
└─────────────────────────────────────────────────────────────────────────────┘

    Markdown Structure:
    ─────────────────────────────────────────────────────────────────────────

    ### Match Example

    **Match Context:**
    [Tournament, round, score, stakes]

    **Table Situation:**
    [Ball positions and layout description]

    **The Decision:**
    [Why this technique was chosen over alternatives]

    **Execution:**
    [Key technique elements performed]

    **Result:**
    [Immediate outcome of the shot]

    **Analysis:**
    [Strategic and technical insight]

    ─────────────────────────────────────────────────────────────────────────

    Attribution Format:
    ─────────────────────────────────────────────────────────────────────────
    • Always credit the player
    • Include event name and year
    • Verify facts before publishing
    • Use neutral, factual language
```

## 6. Training Example Standard

### 6.1 Definition

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          TRAINING EXAMPLE                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose: Guide practice and skill development
    
    When to Use: Every technique article
    Placement: How to Execute or Practice section
    Frequency: 1-3 per article
    
    ─────────────────────────────────────────────────────────────────────────
    
    What Makes It a "Training Example":
    ─────────────────────────────────────────────────────────────────────────
    • Specific drill description
    • Measurable progress markers
    • Progressive difficulty levels
    • Time/intensity guidance
    • Equipment/setup requirements
```

### 6.2 Structure

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       TRAINING EXAMPLE STRUCTURE                             │
└─────────────────────────────────────────────────────────────────────────────┘

    Required Sections:
    ─────────────────────────────────────────────────────────────────────────
    
    ### 1. Drill Name (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Clear, descriptive name
    
    Format: 2-5 words
    Content: What and sometimes how
    
    Example:
    "Draw Shot Line Drill"
    "Multi-Ball Draw Control"
    "Distance Draw Progression"
    
    ### 2. Objective (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    What skill this develops
    
    Format: 1-2 sentences
    Content: Specific skill focus
    
    Example:
    "Develops consistent draw distance control and accuracy at 
    varying lengths."
    
    ### 3. Setup (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Ball positions and equipment
    
    Format: Numbered list of 3-5 items
    Content: Exact positions, distances
    
    Example:
    "1. Place the cue ball at the head spot
    2. Position an object ball 2 feet from the cue ball
    3. Mark positions with chalk or coins
    4. Use a ball return or manually retrieve
    5. Optional: Use a cue ball with alignment dot"
    
    ### 4. Execution (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Step-by-step drill procedure
    
    Format: Numbered list of 4-8 steps
    Content: How to perform
    
    Example:
    "1. Address the cue ball with normal stance
    2. Aim for center of object ball
    3. Place tip ½ tip below center
    4. Execute smooth acceleration through ball
    5. Follow through completely
    6. Observe cue ball behavior
    7. Record where cue ball stops
    8. Adjust power for desired distance"
    
    ### 5. Success Criteria (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    How to measure progress
    
    Format: Bullet list or table
    Content: Specific benchmarks
    
    Example:
    "• Cue ball stops within 6 inches of target: Pass
    • Cue ball stops within 12 inches of target: Developing
    • Cue ball misses target entirely: Needs more practice"
    
    ### 6. Progression (Khuyến Nghị)
    ─────────────────────────────────────────────────────────────────────────
    How to advance
    
    Format: Numbered list of 3-4 levels
    Content: Difficulty increases
    
    Example:
    "1. Level 1: 2-foot shots, large target zone
    2. Level 2: 3-foot shots, smaller target
    3. Level 3: 4-foot shots, specific position
    4. Level 4: 5-foot shots with obstacle navigation"
    
    ### 7. Time Recommendation (Khuyến Nghị)
    ─────────────────────────────────────────────────────────────────────────
    Practice duration
    
    Format: Range with context
    Content: Minutes or repetitions
    
    Example:
    "10-15 minutes daily for 2 weeks
    or
    3 sets of 20 repetitions"
```

### 6.3 Formatting

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       TRAINING EXAMPLE FORMATTING                             │
└─────────────────────────────────────────────────────────────────────────────┘

    Markdown Structure:
    ─────────────────────────────────────────────────────────────────────────

    ### Training Drill: [Drill Name]

    **Objective:**
    [1-2 sentence skill focus]

    **Setup:**
    1. [Setup step 1]
    2. [Setup step 2]
    3. [Setup step 3]

    **Execution:**
    1. [Step 1]
    2. [Step 2]
    3. [Step 3]
    4. [Step 4]

    **Success Criteria:**
    | Level | Criteria | Assessment |
    |-------|----------|-------------|
    | Pass | Within 6 inches | Ready for next level |
    | Developing | Within 12 inches | Continue practice |
    | Needs Work | Missed target | Review fundamentals |

    **Progression:**
    1. Level 1: [Description]
    2. Level 2: [Description]

    **Time:** 10-15 minutes

    ─────────────────────────────────────────────────────────────────────────

    Difficulty Indicator:
    ─────────────────────────────────────────────────────────────────────────
    Use consistent badge format:
    
    🟢 Beginner
    🟡 Intermediate
    🔴 Advanced
    ⚫ Professional
```

## 7. Beginner Example Standard

### 7.1 Definition

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          BEGINNER EXAMPLE                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose: First encounter with the concept for new learners
    
    When to Use: Every article (especially beginner difficulty)
    Placement: Quick Summary or Introduction section
    Frequency: 1 per article, required for beginner content
    
    ─────────────────────────────────────────────────────────────────────────
    
    What Makes It a "Beginner Example":
    ─────────────────────────────────────────────────────────────────────────
    • Simple, relatable scenario
    • Minimal technical jargon
    • Actionable and clear
    • Builds confidence
    • Avoids overwhelming details
```

### 7.2 Structure

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      BEGINNER EXAMPLE STRUCTURE                              │
└─────────────────────────────────────────────────────────────────────────────┘

    Required Sections:
    ─────────────────────────────────────────────────────────────────────────
    
    ### 1. Simple Scenario (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Easy-to-visualize situation
    
    Format: 2-3 sentences
    Content: Everyday pool scenario
    
    Example:
    "You're at a pool hall with friends, playing a casual game. 
    You need to hit the yellow ball into the corner pocket, but 
    your cue ball is a bit too far away."
    
    ### 2. What To Do (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Simple instruction
    
    Format: 1-3 sentences
    Content: Clear action
    
    Example:
    "Here's what you do: hit the cue ball firmly with a smooth 
    follow-through. That's it! The ball will travel where you 
    aimed it."
    
    ### 3. What Happens (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    The result
    
    Format: 1-2 sentences
    Content: Cause and effect
    
    Example:
    "The cue ball pushes forward and hits the yellow ball. The 
    yellow ball rolls into the pocket."
    
    ### 4. Why It Works (Khuyến Nghị)
    ─────────────────────────────────────────────────────────────────────────
    Brief explanation
    
    Format: 1-2 sentences
    Content: Simple reasoning
    
    Example:
    "This works because you're hitting the ball straight on. 
    The harder you hit, the farther it goes."
    
    ### 5. Try It Yourself (Bắt Buộc)
    ─────────────────────────────────────────────────────────────────────────
    Call to action
    
    Format: 1-2 sentences
    Content: Encouragement and next step
    
    Example:
    "Try this yourself! Set up a simple shot and practice hitting 
    straight. Once you can do this consistently, you're ready 
    to learn more advanced shots."
```

### 7.3 Formatting

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       BEGINNER EXAMPLE FORMATTING                             │
└─────────────────────────────────────────────────────────────────────────────┘

    Markdown Structure:
    ─────────────────────────────────────────────────────────────────────────

    ### Beginner Example

    **The Situation:**
    [2-3 sentence simple scenario]

    **Here's What To Do:**
    [1-3 sentence clear instruction]

    **What Happens:**
    [1-2 sentence result description]

    **Why It Works:** *(optional)*
    [1-2 sentence brief explanation]

    **Try It Yourself:**
    [1-2 sentence call to action]

    ─────────────────────────────────────────────────────────────────────────

    Style Guidelines:
    ─────────────────────────────────────────────────────────────────────────
    • Conversational tone ("you", "here's")
    • Short sentences
    • No jargon
    • Encouraging language
    • Concrete details
    • Visual words
```

## 8. Example Quality Standards

### 8.1 Content Requirements

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         CONTENT REQUIREMENTS                                  │
└─────────────────────────────────────────────────────────────────────────────┘

    All Examples Must:
    ─────────────────────────────────────────────────────────────────────────
    
    ✓ Be Accurate
    ─────────────────────────────────────────────────────────────────────────
    • Technical details are correct
    • Ball positions make sense
    • Outcomes are realistic
    • Physics are accurate
    
    ✓ Be Relevant
    ─────────────────────────────────────────────────────────────────────────
    • Directly relate to the article's concept
    • Address common use cases
    • Help with actual application
    • Transferable to reader's situations
    
    ✓ Be Clear
    ─────────────────────────────────────────────────────────────────────────
    • Unambiguous language
    • Logical sequence
    • Specific details
    • No confusion about positions or actions
    
    ✓ Be Balanced
    ─────────────────────────────────────────────────────────────────────────
    • Not too simple (insulting)
    • Not too complex (overwhelming)
    • Appropriate for difficulty level
    • Progressive when showing progression
```

### 8.2 Language Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          LANGUAGE STANDARDS                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    Voice and Tone:
    ─────────────────────────────────────────────────────────────────────────
    
    Practical Examples:
    ─────────────────────────────────────────────────────────────────────────
    • Objective, instructional
    • Third person narrative
    • Technical but accessible
    • Clear cause-effect language
    
    Match Examples:
    ─────────────────────────────────────────────────────────────────────────
    • Factual, descriptive
    • Neutral reporting tone
    • Focus on decision, not personality
    • Respectful of players
    
    Training Examples:
    ─────────────────────────────────────────────────────────────────────────
    • Directive, encouraging
    • Second person acceptable
    • Clear instruction language
    • Positive framing
    
    Beginner Examples:
    ─────────────────────────────────────────────────────────────────────────
    • Conversational, friendly
    • Second person ("you")
    • Simple vocabulary
    • Encouraging, builds confidence
```

### 8.3 Formatting Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         FORMATTING STANDARDS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    Section Headers:
    ─────────────────────────────────────────────────────────────────────────
    Use consistent formatting per example type:
    
    Practical: "### Practical Example"
    Match:      "### Match Example"
    Training:   "### Training Drill: [Name]"
    Beginner:    "### Beginner Example"
    
    Emphasis:
    ─────────────────────────────────────────────────────────────────────────
    • Bold for key terms and concepts
    • Italic for technique names
    • Code for measurements/positions
    
    Lists:
    ─────────────────────────────────────────────────────────────────────────
    • Numbered for sequences and steps
    • Bullets for criteria and tips
    • Tables for comparisons and benchmarks
    
    Spacing:
    ─────────────────────────────────────────────────────────────────────────
    • One blank line between sections
    • No excessive blank lines
    • Consistent indentation
```

## 9. Visual Elements

### 9.1 Ball Position Diagrams

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      BALL POSITION DIAGRAMS                                  │
└─────────────────────────────────────────────────────────────────────────────┘

    ASCII Diagram Format:
    ─────────────────────────────────────────────────────────────────────────

    Table Layout:

    ┌─────────────────────────────────────┐
    │  ●                                   │  ← Corner pocket
    │         1                            │  ← Object ball
    │                   2                  │  ← Obstacle ball
    │    ○                                 │  ← Cue ball
    │                                       │
    │  ●                          ●         │
    └─────────────────────────────────────┘
              ●                  ●

    Legend:
    ─────────────────────────────────────────────────────────────────────────
    ○ = Cue ball
    ● = Object ball
    ◐ = Partially visible ball
    ★ = Target pocket
    █ = Obstacle/blocking ball
    
    Example:
    ─────────────────────────────────────────────────────────────────────────

    ```
    ┌─────────────────────────────────────┐
    │ ★                                 ★ │
    │                                     │
    │           ●─────────────────        │  ← Line of balls
    │                   2                 │
    │                 ○                   │  ← Cue ball
    │                                     │
    │ ★                                 ★ │
    └─────────────────────────────────────┘
              ●                  ●
    ```
    
    Shot Path:
    ─────────────────────────────────────────────────────────────────────────
    
    ```
    ○ ──────────→ ●
         │
         │ ←── draw back
         ▼
    ```
```

### 9.2 Measurement Formatting

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       MEASUREMENT FORMATTING                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    Distance Format:
    ─────────────────────────────────────────────────────────────────────────
    • Use feet and inches consistently
    • Example: "2 feet", "6 inches"
    • In technical content: "2 ft (61 cm)"
    
    Position Format:
    ─────────────────────────────────────────────────────────────────────────
    • Relative positions: "behind the 3-ball"
    • Distance from cushion: "6 inches from the rail"
    • Angle descriptions: "45-degree angle"
    
    Shot Parameters:
    ─────────────────────────────────────────────────────────────────────────
    • Tip placement: "½ tip below center"
    • Power: "medium acceleration", "70% power"
    • Spin: "light draw", "heavy backspin"
```

    [ ] Learning point included
    [ ] Context is sufficient
    [ ] Instructions are actionable
    
    □ Formatting
    ─────────────────────────────────────────────────────────────────────────
    [ ] Correct template applied
    [ ] Consistent heading style
    [ ] Lists properly formatted
    [ ] Diagrams are clear
    
    □ Appropriateness
    ─────────────────────────────────────────────────────────────────────────
    [ ] Difficulty level matches
    [ ] Technical depth appropriate
    [ ] Language accessible
    [ ] Length proportional
