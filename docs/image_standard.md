# BKM - Image Standards

## Version 1.0
**Last Updated:** July 2026
**Status:** Production Standard

---

## 1. Overview

This document establishes standards for all images used in the BKM Knowledge Base. Consistent image standards ensure visual clarity, brand coherence, accessibility, and proper asset management.

---

### 2.1 Instructional Images

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         INSTRUCTIONAL IMAGES                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose:
    ─────────────────────────────────────────────────────────────────────────
    Demonstrate technique execution, ball positions, stance, grip, 
    or any physical aspect of billiards that requires visual instruction.

    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Clear, uncluttered visuals
    • Minimal elements (only what's being taught)
    • Annotation and labeling where helpful
    • Consistent perspective (usually overhead or side view)
    • Highlighted areas of focus

    Examples:
    ─────────────────────────────────────────────────────────────────────────
    • Cue grip demonstration
    • Bridge formation guide
    • Ball position diagram
    • Shot angle illustration
    • Follow-through sequence
```

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            DIAGRAM IMAGES                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose:
    ─────────────────────────────────────────────────────────────────────────

    processes that cannot be easily shown with photography.

    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Simplified, symbolic representation

    • Clean, professional appearance

    Examples:
    ─────────────────────────────────────────────────────────────────────────
    • Table layout diagram
    • Shot angle visualization
    • Spin direction diagram
    • Training progression flowchart
    • Equipment comparison chart
```

## 3. Visual Style Standards

### 3.1 Art Direction

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          ART DIRECTION                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    OVERALL STYLE
    ─────────────────────────────────────────────────────────────────────────
    Modern, clean, professional with a focus on clarity and 
    educational value. Style should complement the content 
    without distracting from it.

    ─────────────────────────────────────────────────────────────────────────

    COLOR PALETTE FOR DIAGRAMS
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Element            │ Primary Color    │ Hex Code                  │
    │   ──────────────────┼──────────────────┼────────────────────────── │
    │   Cue Ball          │ White            │ #FFFFFF                    │
    │   Object Ball       │ Yellow           │ #FFD700                    │
    │   Striped Ball      │ Blue stripe      │ #0066CC with white stripe  │
    │   8-Ball            │ Black            │ #000000                    │
    │   Pocket            │ Dark Gray        │ #333333                    │
    │   Table Felt        │ Pool Green       │ #0B6623                    │
    │   Table Rails       │ Dark Wood        │ #4A2C2A                    │
    │   Highlight/Action  │ Bright Red       │ #FF3B30                    │
    │   Annotation        │ Blue             │ #007AFF                    │
    │   Arrow/Direction   │ Orange           │ #FF9500                    │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    ILLUSTRATION STYLE
    ─────────────────────────────────────────────────────────────────────────

    Instruction/Diagram:
    ─────────────────────────────────────────────────────────────────────────
    • Clean vector style
    • Flat design with subtle gradients
    • Consistent stroke width (2-3px)
    • Rounded corners where appropriate
    • Minimal shadow (flat style preferred)

    Photo Reference:
    ─────────────────────────────────────────────────────────────────────────
    • High contrast, vivid colors
    • Sharp focus
    • Professional composition
    • Natural or studio lighting

    ─────────────────────────────────────────────────────────────────────────

    TYPOGRAPHY IN IMAGES
    ─────────────────────────────────────────────────────────────────────────

    Font Requirements:
    ─────────────────────────────────────────────────────────────────────────
    • Sans-serif font (Inter, Roboto, or system font)
    • Minimum font size: 12px (readable at image scale)
    • Label font size: 10-14px
    • Heading font size: 16-20px
    • Bold weight for emphasis
    • High contrast against background

    Label Style:
    ─────────────────────────────────────────────────────────────────────────
    • White text with dark outline OR
    • Dark text with light outline
    • Background pill/badge for readability
```

### 3.2 Annotation Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ANNOTATION STANDARDS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    ANNOTATION TYPES
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Type          │ Use Case                  │ Style                  │
    │   ─────────────┼──────────────────────────┼───────────────────────── │
    │   Arrow        │ Point to element          │ Solid line, arrowhead  │
    │   Circle       │ Highlight area of focus   │ Dashed or solid ring   │
    │   Rectangle    │ Frame specific area       │ Rounded corners         │
    │   Line         │ Show path, angle          │ With/without arrow     │
    │   Text Label   │ Name element              │ With outline/bg        │
    │   Number       │ Sequential steps          │ Circle badge           │
    │   Highlight    │ Emphasis area             │ Semi-transparent fill  │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    ANNOTATION STYLE GUIDE
    ─────────────────────────────────────────────────────────────────────────

    Arrow Annotations:
    ─────────────────────────────────────────────────────────────────────────
    • Line color: #FF9500 (Orange) or #007AFF (Blue)
    • Line width: 3px
    • Arrow head: 12px triangle
    • Dashed for optional paths

    Circle Annotations:
    ─────────────────────────────────────────────────────────────────────────
    • Stroke: 3px, #FF3B30 (Red) or #007AFF (Blue)
    • Fill: Semi-transparent (20% opacity)
    • Radius: Sized to element plus 10% padding

    Numbered Steps:
    ─────────────────────────────────────────────────────────────────────────
    • Badge: 24px circle
    • Background: #007AFF
    • Text: White, 14px, bold
    • Position: Top-left of element

    Text Labels:
    ─────────────────────────────────────────────────────────────────────────
    • Background: #000000 (80% opacity) or #FFFFFF (90% opacity)
    • Padding: 4px 8px
    • Corner radius: 4px
    • Text: 12px, matching bg contrast
```

### 3.3 Icon Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            ICON STANDARDS                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    ICON SET
    ─────────────────────────────────────────────────────────────────────────
    Use consistent iconography across all instructional content.

    Recommended Icons:
    ─────────────────────────────────────────────────────────────────────────
    • Cue stick icon for technique articles
    • Ball icon for shots and balls
    • Pocket icon for pocket-related content
    • Target icon for aims and objectives
    • Checkmark for success criteria
    • Arrow for directions and sequences

    ─────────────────────────────────────────────────────────────────────────

    ICON STYLE
    ─────────────────────────────────────────────────────────────────────────
    • Style: Line or filled (consistent per image)
    • Stroke width: 2px
    • Size: 24px standard, 16px small, 32px large
    • Color: #333333 for standard, themed for accent
    • Spacing: 8px minimum from other elements

    ─────────────────────────────────────────────────────────────────────────

    CUSTOM ICONS
    ─────────────────────────────────────────────────────────────────────────
    When creating custom icons:
    • Use vector format (SVG)
    • Follow grid system (24px base)
    • Maintain consistent visual weight
    • Test at multiple sizes
```

## 4. Background Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         BACKGROUND STANDARDS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    PURPOSE-SPECIFIC BACKGROUNDS
    ─────────────────────────────────────────────────────────────────────────

    Instructional/Diagram Images:
    ─────────────────────────────────────────────────────────────────────────
    Background: Transparent OR solid color

    ✓ PREFERRED
    • Transparent (PNG with alpha)
    • #FFFFFF (white) for light mode
    • #F5F5F7 (light gray) for subtle contrast
    • #0B6623 (pool green) for table context

    ✗ AVOID
    • Complex patterns that distract
    • Photographic backgrounds
    • Low contrast elements

    ─────────────────────────────────────────────────────────────────────────

    Reference/Photo Images:
    ─────────────────────────────────────────────────────────────────────────
    Background: Natural or removed

    ✓ PREFERRED
    • Natural context (venue, room)
    • Studio backdrop (white or gray)
    • Background removed (product shots)

    ✗ AVOID
    • Cluttered backgrounds
    • Distracting elements
    • Inconsistent lighting

    ─────────────────────────────────────────────────────────────────────────

    WEB/DIGITAL IMAGES:
    ─────────────────────────────────────────────────────────────────────────
    Background: Optimized for display

    ✓ PREFERRED
    • Transparent for overlay usage
    • White for standalone display
    • Match article background color

    ─────────────────────────────────────────────────────────────────────────

    BACKGROUND CONSISTENCY
    ─────────────────────────────────────────────────────────────────────────

    Within Single Article:
    ─────────────────────────────────────────────────────────────────────────
    • Use consistent background per image type
    • All instructional images: transparent or same bg
    • All diagrams: same style and bg
    • All reference photos: similar treatment

    Across Articles:
    ─────────────────────────────────────────────────────────────────────────
    • Same purpose = same background style
    • Consistent color palette usage
    • Unified visual language
```

## 5. Aspect Ratio Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          ASPECT RATIO STANDARDS                              │
└─────────────────────────────────────────────────────────────────────────────┘

    STANDARD RATIOS
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Ratio         │ Dimensions   │ Use Case                             │
    │   ─────────────┼───────────────┼───────────────────────────────────── │
    │   1:1          │ Square        │ Icons, avatars, thumbnails           │
    │   4:3          │ Standard      │ General instructional, diagrams       │
    │   16:9         │ Widescreen    │ Video frames, wide layouts           │
    │   16:10        │ Business      │ Presentation-style content          │
    │   3:2          │ Photo         │ Reference photos, galleries          │
    │   9:16         │ Portrait      │ Mobile content, vertical tutorials   │
    │   2:1          │ Cinematic     │ Comparison layouts                  │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    PURPOSE-SPECIFIC RATIOS
    ─────────────────────────────────────────────────────────────────────────

    Instructional Diagrams:
    ─────────────────────────────────────────────────────────────────────────
    Ratio: 16:9 or 4:3
    Reason: Optimal for showing technique with context

    Example dimensions: 1920×1080, 1600×1200, 800×600

    ─────────────────────────────────────────────────────────────────────────

    Ball Position Diagrams:
    ─────────────────────────────────────────────────────────────────────────
    Ratio: 2:1 or 5:4
    Reason: Matches table proportions

    Example dimensions: 1000×500, 1000×800

    ─────────────────────────────────────────────────────────────────────────

    Step-by-Step Sequences:
    ─────────────────────────────────────────────────────────────────────────
    Ratio: 1:1 or 4:3
    Reason: Even spacing, easy comparison

    Example dimensions: 800×800, 1200×900

    ─────────────────────────────────────────────────────────────────────────

    Full Table Overviews:
    ─────────────────────────────────────────────────────────────────────────
    Ratio: 2:1 (table ratio)
    Reason: Accurate representation

    Example dimensions: 1400×700, 2800×1400

    ─────────────────────────────────────────────────────────────────────────

    Comparison Layouts:
    ─────────────────────────────────────────────────────────────────────────
    Ratio: 16:9
    Reason: Side-by-side optimal

    Example dimensions: 1920×1080

    ─────────────────────────────────────────────────────────────────────────

    PORTRAIT CONTENT
    ─────────────────────────────────────────────────────────────────────────

    When 9:16 is Required:
    ─────────────────────────────────────────────────────────────────────────
    • Mobile-first articles
    • Vertical video thumbnails
    • Social media content
    • Side-by-side step display

    Note: Convert 16:9 content to 9:16 only when necessary.
```

## 6. Resolution Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         RESOLUTION STANDARDS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    RESOLUTION TIERS
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Tier          │ Dimensions      │ DPI        │ Use Case            │
    │   ─────────────┼─────────────────┼────────────┼────────────────────  │
    │   Thumbnail    │ 150×150 max    │ 72-96 DPI  │ Lists, previews     │
    │   Small       │ 400-800px wide │ 96 DPI     │ Inline content      │
    │   Medium      │ 800-1200px wide│ 96 DPI     │ Standard display    │
    │   Large       │ 1200-2000px wide│ 96-150 DPI │ Full-width display │
    │   High Res    │ 2000px+ wide   │ 150-300 DPI│ Print, zoomable     │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    WEB DISPLAY STANDARDS
    ─────────────────────────────────────────────────────────────────────────

    Recommended Maximum Widths:
    ─────────────────────────────────────────────────────────────────────────
    • Inline (in paragraph): 400px
    • Half-width (side by side): 600px
    • Full-width (article width): 1200px
    • Hero (full bleed): 1920px

    Resolution for Display:
    ─────────────────────────────────────────────────────────────────────────
    • Standard: 96 DPI
    • Retina/High-DPI: 192 DPI (2x for retina)

    ─────────────────────────────────────────────────────────────────────────

    FILE SIZE GUIDELINES
    ─────────────────────────────────────────────────────────────────────────

    Maximum File Sizes:
    ─────────────────────────────────────────────────────────────────────────
    • Thumbnail: 30 KB
    • Small: 100 KB
    • Medium: 250 KB
    • Large: 500 KB
    • High Res: 2 MB (acceptable for quality)

    Format-Specific Sizes:
    ─────────────────────────────────────────────────────────────────────────
    • PNG: Use for diagrams, transparency
    • JPEG: Use for photos, compress to quality 80-85%
    • WebP: Preferred for web, 30% smaller than PNG/JPEG
    • SVG: Use for icons, diagrams (vector)

    ─────────────────────────────────────────────────────────────────────────

    PROPORTIONAL SIZING
    ─────────────────────────────────────────────────────────────────────────

    Always Maintain Aspect Ratio:
    ─────────────────────────────────────────────────────────────────────────

    ✓ CORRECT
    Original: 1600×900 (16:9)
    Scaled: 800×450 (16:9) ✓

    ✗ INCORRECT
    Original: 1600×900
    Scaled: 800×600 (changed ratio) ✗

    ─────────────────────────────────────────────────────────────────────────

    RESPONSIVE SIZING
    ─────────────────────────────────────────────────────────────────────────

    Provide multiple sizes for responsive images:

    <img src="diagram-800w.webp"
         srcset="diagram-400w.webp 400w,
                 diagram-800w.webp 800w,
                 diagram-1200w.webp 1200w"
         sizes="(max-width: 600px) 400px,
                (max-width: 1200px) 800px,
                1200px"
         alt="Description">

    Responsive Breakpoints:
    ─────────────────────────────────────────────────────────────────────────
    • Mobile: 400px
    • Tablet: 800px
    • Desktop: 1200px
    • Large: 1600px
```

## 7. File Naming Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          FILE NAMING STANDARDS                              │
└─────────────────────────────────────────────────────────────────────────────┘

    NAMING CONVENTION
    ─────────────────────────────────────────────────────────────────────────

    Format: {category}-{subcategory}-{descriptor}-{number?}.{ext}

    Components:
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Component      │ Description                    │ Examples          │
    │   ──────────────┼────────────────────────────────┼─────────────────── │
    │   category      │ Broad content category         │ technique, shot,  │
    │                 │                                │ equipment, table  │
    │   subcategory   │ Specific type within category  │ draw, follow,     │
    │                 │                                │ stance, grip      │
    │   descriptor    │ Unique identifier              │ angle-demo,       │
    │                 │                                │ position-01       │
    │   number        │ Sequence for multiple images   │ 01, 02, 03        │
    │   ext           │ File extension                │ png, jpg, webp,   │
    │                 │                                │ svg               │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    NAMING EXAMPLES
    ─────────────────────────────────────────────────────────────────────────

    ✓ CORRECT NAMING

    technique-draw-basic-execution-01.png
    └─category─┘ └sub─┘ └─descriptor──┘ └n┘

    shot-follow-angle-diagram.svg
    └─category─┘ └────sub─────┘ └─desc─┘

    equipment-cue-grip-variations-02.jpg
    └─category─┘ └─sub─┘ └────descriptor──┘┘

    table-layout-full-overview.webp
    └─category─┘ └─sub───┘ └───desc──────┘

    ─────────────────────────────────────────────────────────────────────────

    ✗ INCORRECT NAMING

    IMG_1234.png           ← No category
    draw shot.png          ← Spaces
    DRAW_SHOT-01.png       ← Uppercase
    technique-01-final.png ← Vague descriptor
    img1.jpg               ← Meaningless

    ─────────────────────────────────────────────────────────────────────────

    CATEGORY PREFIXES
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Prefix         │ Category                                       │
    │   ──────────────┼────────────────────────────────────────────────  │
    │   technique-    │ Technique instruction                           │
    │   shot-         │ Shot types and demonstrations                   │
    │   equipment-    │ Equipment images                                │
    │   table-        │ Table and layout diagrams                       │
    │   player-       │ Reference photos of players                      │
    │   event-        │ Tournament and event photos                      │
    │   ui-           │ User interface screenshots                       │
    │   icon-         │ Icons and small graphics                        │
    │   diagram-      │ General diagrams and charts                     │
    │   banner-       │ Header and promotional images                    │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    VARIANT NAMING
    ─────────────────────────────────────────────────────────────────────────

    For size variants:

    {base-name}-{size}.{ext}

    Example:
    technique-draw-execution-01-400w.webp
    technique-draw-execution-01-800w.webp
    technique-draw-execution-01-1200w.webp

    ─────────────────────────────────────────────────────────────────────────

    VERSION NAMING
    ─────────────────────────────────────────────────────────────────────────

    For revisions:

    {base-name}-v{number}.{ext}

    Example:
    technique-stance-demo-v1.png
    technique-stance-demo-v2.png

    ─────────────────────────────────────────────────────────────────────────

    SPECIAL CHARACTERS
    ─────────────────────────────────────────────────────────────────────────

    Allowed:
    • Hyphens (-) as word separator
    • Underscores (_) for technical naming
    • Numbers (0-9) anywhere

    Not Allowed:
    • Spaces
    • Special characters (!@#$%^&*()+=[]{}|)
    • Unicode characters
    • Capital letters
```

## 8. Caption Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           CAPTION STANDARDS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    CAPTION REQUIREMENTS
    ─────────────────────────────────────────────────────────────────────────
    Every image MUST have a caption that describes its content 
    clearly and provides necessary context.

    ─────────────────────────────────────────────────────────────────────────

    CAPTION STRUCTURE
    ─────────────────────────────────────────────────────────────────────────

    Format: {Type} - {Description} ({Context})

    Components:
    ─────────────────────────────────────────────────────────────────────────

    Type: What kind of image this is
    • "Diagram"
    • "Illustration"
    • "Photo"
    • "Screenshot"
    • "Step X of Y"

    Description: What the image shows
    • Brief, clear description
    • Focus on relevant elements
    • Use active voice

    Context: Additional info if needed
    • Perspective (overhead, side view)
    • Time period for historical
    • Attribution for reference

    ─────────────────────────────────────────────────────────────────────────

    CAPTION EXAMPLES
    ─────────────────────────────────────────────────────────────────────────

    ✓ CORRECT

    "Diagram - Ball positions for a basic draw shot setup. 
    Overhead view showing cue ball, object ball, and target pocket."

    "Step 1 of 3 - Correct open bridge formation. 
    Side view demonstrating hand placement on the table."

    "Photo - Professional player demonstrating proper 
    stance. Note the shoulder alignment with the shot line."

    "Illustration - Spin direction indicators showing 
    inside english versus outside english contact points."

    "Screenshot - Training log interface showing shot 
    accuracy statistics. Displaying weekly progress chart."

    ─────────────────────────────────────────────────────────────────────────

    ✗ INCORRECT

    "Image"
    "Picture of ball"
    "IMG_1234"
    "See above"
    "As shown"

    ─────────────────────────────────────────────────────────────────────────

    CAPTION STYLE
    ─────────────────────────────────────────────────────────────────────────

    Length:
    • Minimum: 10 words
    • Maximum: 50 words
    • Optimal: 15-30 words

    Tone:
    • Descriptive, not evaluative
    • Factual, not promotional
    • Clear, not technical jargon
    • Accessible to beginner level

    Formatting:
    • First word capitalized
    • No period at end
    • Italicize image type
    • Quotation marks only for direct quotes in photo

    ─────────────────────────────────────────────────────────────────────────

    ACCESSIBILITY CAPTIONS
    ─────────────────────────────────────────────────────────────────────────

    Alt Text (for screen readers):
    ─────────────────────────────────────────────────────────────────────────

    Write alt text that:
    • Describes the visual content
    • Conveys the same information as the image
    • Is concise (125 characters or less)
    • Does not start with "Image of" or "Picture of"

    Example:

    Caption: "Diagram - Draw shot cue ball path showing 
    contact point and resulting trajectory."

    Alt Text: "Overhead view of pool table showing cue 
    ball curving back after hitting object ball"

    ─────────────────────────────────────────────────────────────────────────

    FIGURE NUMBERING
    ─────────────────────────────────────────────────────────────────────────

    Format: Figure X. {Description}

    Example:
    "Figure 1. Draw shot setup positions"
    "Figure 2. Common grip mistakes"
    "Figure 3. Training drill progression"

    Use sequential numbering within articles.
```

    ─────────────────────────────────────────────────────────────────────────

    ORIGINAL BKM IMAGES
    ─────────────────────────────────────────────────────────────────────────

    BKM owns all original images created for the platform.

    Requirements:
    ─────────────────────────────────────────────────────────────────────────
    • Created by BKM team members or contractors
    • Created specifically for BKM content
    • No third-party elements incorporated
    • Work-for-hire agreement in place

    Watermark:
    ─────────────────────────────────────────────────────────────────────────
    Optional for high-value images. If used:
    • Position: Bottom-right corner
    • Opacity: 30%
    • Size: 10% of image width
    • Content: "© BKM" or BKM logo

    ─────────────────────────────────────────────────────────────────────────

    LICENSED IMAGES
    ─────────────────────────────────────────────────────────────────────────

    When using third-party images:

    License Types:
    ─────────────────────────────────────────────────────────────────────────
    • Stock photos: Purchase from iStock, Shutterstock, etc.
    • Creative Commons: Verify CC license type
    • Rights-managed: Document usage terms
    • Editorial use: For news/reference only

    Documentation Required:
    ─────────────────────────────────────────────────────────────────────────
    □ License agreement on file
    □ Usage terms verified
    □ Attribution requirements met
    □ Expiration date tracked (if applicable)
    □ Territory limitations checked

    Attribution Format:
    ─────────────────────────────────────────────────────────────────────────

    Image Credit Line Format:
    Photo: {Creator Name} / {License/Source}

    Examples:
    "Photo: John Smith / Shutterstock"
    "Photo: Jane Doe / Creative Commons BY 4.0"
    "Photo: International Pool Tour / Editorial Use"

    Placement: Below caption or in image credit section

    ─────────────────────────────────────────────────────────────────────────

    PUBLIC DOMAIN IMAGES
    ─────────────────────────────────────────────────────────────────────────

    Public Domain Criteria:
    ─────────────────────────────────────────────────────────────────────────
    • Copyright expired
    • CC0 license (no rights reserved)
    • Government work (US federal)
    • Never copyrighted

    Verification:
    ─────────────────────────────────────────────────────────────────────────
    □ Source confirms public domain status
    □ License text explicitly states "No rights reserved"
    □ Age of work exceeds copyright term
    □ Official government publication

    Note: When in doubt, treat as requiring license.

    ─────────────────────────────────────────────────────────────────────────

    FAIR USE GUIDELINES
    ─────────────────────────────────────────────────────────────────────────

    Fair use may apply for:
    ─────────────────────────────────────────────────────────────────────────
    • Educational commentary
    • Criticism and review
    • News reporting
    • Scholarship and research

    Fair use factors considered:
    ─────────────────────────────────────────────────────────────────────────
    1. Purpose and character of use
    2. Nature of the copyrighted work
    3. Amount used relative to whole
    4. Effect on market value

    ⚠️ WARNING: Fair use is a legal defense, not a right.
    Consult legal counsel for significant uses.
