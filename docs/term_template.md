# BKM - Term Template

## Version 1.0
**Last Updated:** July 2026
**Status:** Production Standard

---

## 1. Overview

This template provides a blank structure for creating new terms. Copy and fill in the placeholders.

---

## 2. Template Structure

```markdown
# {TERM_NAME}

## Quick Definition
{One sentence definition in English}
{One sentence definition in Vietnamese}

## Definition

### English
{Full definition in English - 500-2000 characters}

### Vietnamese
{Full definition in Vietnamese - 500-2000 characters}

## Pronunciation
- English: {IPA pronunciation}
- Vietnamese: {Vietnamese pronunciation}

## Aliases
- {Alternative name 1}
- {Alternative name 2}

## Category
- Primary: {Category Name}
- Path: {bkm > parent > child}

## Difficulty
{Beginner | Intermediate | Advanced | Professional}

## Prerequisites
- {Required prerequisite term}
- {Recommended prerequisite term}

## Related Terms
- {Related term 1} - {relationship type}
- {Related term 2} - {relationship type}

## Key Points
1. {Key point 1}
2. {Key point 2}
3. {Key point 3}

## Common Mistakes
| Mistake | Cause | Correction |
|---------|-------|------------|
| {Mistake} | {Cause} | {Correction} |

## Drills
### {Drill Name}
- Difficulty: {Beginner | Intermediate | Advanced}
- Duration: {X} minutes
- Equipment: {Required equipment}
- Instructions:
  {Step-by-step instructions}

## Media
- Hero Image: {file-name-hero.webp}
- Diagram: {file-name-diagram.svg}
- Video: {file-name-tutorial.mp4}

## Notes
{Additional notes and tips}

## References
- {Reference 1}
- {Reference 2}

---

**Metadata**
- ID: {TERM-NNNNNN}
- Slug: {term-slug}
- Status: Draft
- Created: {YYYY-MM-DD}
- Updated: {YYYY-MM-DD}
```

---

## 3. Checklist

Before publishing a term, verify:

- [ ] English name provided
- [ ] Vietnamese name provided
- [ ] Short definition (50-150 chars) completed
- [ ] Full definition (500-2000 chars) completed
- [ ] Category assigned
- [ ] Difficulty level set
- [ ] At least one media asset attached
- [ ] Related terms linked
- [ ] Tags assigned
- [ ] Review completed
- [ ] No placeholder text remaining
