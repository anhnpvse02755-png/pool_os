# BKM - Content Writing Priority

## Version 1.0
**Last Updated:** July 2026
**Status:** Production Standard

---

## 1. Overview

This document defines the writing priority order for content development. Categories are grouped into four levels based on user impact, learning dependencies, and business value.

---

## 2. Priority Level Definitions

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         PRIORITY LEVELS                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │  Level 1: ESSENTIAL                                                │
    │  ─────────────────────────────────────────────────────────────────  │
    │  • Core vocabulary every player needs                               │
    │  • No prerequisites - can be learned immediately                   │
    │  • High frequency of use                                            │
    │  • Foundation for all other learning                               │
    │                                                                      │
    │  Level 2: IMPORTANT                                                │
    │  ─────────────────────────────────────────────────────────────────  │
    │  • Builds on Level 1 knowledge                                     │
    │  • High value for skill development                                 │
    │  • Moderate complexity                                             │
    │  • Common intermediate scenarios                                    │
    │                                                                      │
    │  Level 3: ADVANCED                                                 │
    │  ─────────────────────────────────────────────────────────────────  │
    │  • Requires solid foundation (Level 1-2)                           │
    │  • Lower frequency but high impact                                  │
    │  • Competitive advantage                                           │
    │  • Professional/expert level                                       │
    │                                                                      │
    │  Level 4: REFERENCE                                                │
    │  ─────────────────────────────────────────────────────────────────  │
    │  • Lookup value only                                                │
    │  • Low frequency of use                                            │
    │  • Specialized or historical knowledge                              │
    │  • Nice to have but not required                                   │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘
```
