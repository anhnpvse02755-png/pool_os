# BKM - Video Standards

## Version 1.0
**Last Updated:** July 2026
**Status:** Production Standard

---

## 1. Overview

This document establishes standards for all video content in the BKM Knowledge Base. Consistent video standards ensure quality viewing experiences, effective searchability, accessibility, and proper content management.

### 2.1 Tutorial Videos

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            TUTORIAL VIDEOS                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose:
    ─────────────────────────────────────────────────────────────────────────
    Step-by-step instructional content that teaches specific techniques, 
    skills, or concepts with clear learning objectives.

    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Clear learning objective stated at start
    • Segmented sections with visual markers
    • Demonstrates correct and incorrect execution
    • Includes practice tips and common mistakes
    • Call-to-action for practice

    Duration: 3-15 minutes (depending on complexity)
    Difficulty: Beginner to Advanced

    Structure:
    ─────────────────────────────────────────────────────────────────────────
    1. Introduction (10-15 sec)
       - Topic announcement
       - What viewer will learn
       - Prerequisite skills

    2. Core Instruction (70% of video)
       - Technique breakdown
       - Demonstration
       - Common errors
       - Practice drill

    3. Conclusion (10-15 sec)
       - Key takeaways
       - Next steps
       - Practice encouragement
```

### 2.2 Demonstration Videos

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         DEMONSTRATION VIDEOS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose:
    ─────────────────────────────────────────────────────────────────────────
    Real-time execution of skills and techniques, showing professional 
    or expert-level performance for reference and inspiration.

    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Real-time execution without editing shortcuts
    • Multiple camera angles for key moments
    • Slow-motion for complex movements
    • Minimal narration (visual speaks)
    • Professional quality execution

    Duration: 1-10 minutes
    Difficulty: Intermediate to Expert

    Structure:
    ─────────────────────────────────────────────────────────────────────────
    1. Setup Shot (5-10 sec)
       - Show initial positions
       - Camera angle established

    2. Execution (80% of video)
       - Full shot execution
       - Multiple attempts
       - Varied perspectives

    3. Result Review (10-20 sec)
       - Slow-motion replay
       - Angle analysis
       - Outcome display
```

### 2.3 Explanation Videos

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          EXPLANATION VIDEOS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose:
    ─────────────────────────────────────────────────────────────────────────
    Concept and theory breakdowns that explain the "why" behind techniques, 
    strategies, and principles.

    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Visual aids (diagrams, animations)
    • Conceptual clarity prioritized
    • Logical progression of ideas
    • Examples to illustrate points
    • Educational narrative

    Duration: 5-20 minutes
    Difficulty: All levels

    Structure:
    ─────────────────────────────────────────────────────────────────────────
    1. Concept Introduction (30-60 sec)
       - Topic overview
       - Importance explained
       - Learning outcomes

    2. Theory Breakdown (60% of video)
       - Core concepts explained
       - Visual demonstrations
       - Related principles
       - Examples and analogies

    3. Practical Application (25% of video)
       - How to apply theory
       - Practice approach
       - Integration with other skills

    4. Summary (5-10 sec)
       - Key points recap
       - Further learning paths
```

### 2.4 Analysis Videos

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           ANALYSIS VIDEOS                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose:
    ─────────────────────────────────────────────────────────────────────────
    In-depth review and breakdown of matches, games, or professional 
    plays to teach strategy and decision-making.

    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Strategic thinking focus
    • Decision analysis
    • Multiple perspectives
    • What-if scenarios
    • Educational commentary

    Duration: 10-45 minutes
    Difficulty: Advanced to Professional

    Structure:
    ─────────────────────────────────────────────────────────────────────────
    1. Context Setting (1-2 min)
       - Players/teams introduction
       - Match situation
       - Stakes explained

    2. Play-by-Play Analysis (85% of video)
       - Critical moments highlighted
       - Decision rationale
       - Alternative options
       - Outcome analysis

    3. Takeaways (1-2 min)
       - Key lessons
       - Strategic insights
       - How to apply
```

### 2.5 Drill Guide Videos

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           DRILL GUIDE VIDEOS                                │
└─────────────────────────────────────────────────────────────────────────────┘

    Purpose:
    ─────────────────────────────────────────────────────────────────────────
    Training exercise demonstrations that provide structured practice 
    routines for skill development.

    Characteristics:
    ─────────────────────────────────────────────────────────────────────────
    • Clear drill setup instructions
    • Repetition focus
    • Progression levels
    • Success criteria defined
    • Practice schedule suggestions

    Duration: 2-10 minutes
    Difficulty: Beginner to Advanced

    Structure:
    ─────────────────────────────────────────────────────────────────────────
    1. Drill Introduction (20-30 sec)
       - Skill target
       - Difficulty level
       - Time requirement

    2. Setup Instructions (30-60 sec)
       - Ball positions shown
       - Equipment needed
       - Space requirements

    3. Execution Guide (60% of video)
       - Step-by-step execution
       - Common mistakes
       - Correction tips
       - Progression stages

    4. Practice Plan (20-30 sec)
       - Repetitions recommended
       - Frequency suggestions
       - Difficulty progression
```

## 3. Video Length Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          LENGTH STANDARDS                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    PURPOSE-BASED LENGTH
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Purpose          │ Optimal      │ Acceptable    │ Avoid           │
    │   ───────────────┼──────────────┼───────────────┼───────────────── │
    │   Tutorial        │ 5-10 min    │ 3-15 min     │ >20 min        │
    │   Demonstration   │ 2-5 min     │ 1-10 min     │ >15 min        │
    │   Explanation     │ 8-15 min    │ 5-20 min     │ >25 min        │
    │   Analysis        │ 15-30 min   │ 10-45 min    │ >60 min        │
    │   Drill Guide     │ 3-6 min     │ 2-10 min     │ >15 min        │
    │   Equipment       │ 5-10 min    │ 3-20 min     │ >30 min        │
    │   Documentary     │ 10-20 min   │ 5-45 min     │ >60 min        │
    │   Highlights      │ 2-5 min     │ 1-10 min     │ >15 min        │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    PLATFORM-SPECIFIC OPTIMIZATION
    ─────────────────────────────────────────────────────────────────────────

    YouTube:
    ─────────────────────────────────────────────────────────────────────────
    • Optimal: 8-15 minutes (engagement metrics)
    • Short: 1-3 minutes (YouTube Shorts)
    • Long-form: 15-45 minutes (educational content)
    • Minimum: 30 seconds
    • Maximum: No hard limit, but >60 min loses engagement

    Social Media (Instagram/TikTok):
    ─────────────────────────────────────────────────────────────────────────
    • Reels/Shorts: 15-60 seconds
    • Stories: 15 seconds per segment
    • Feed videos: 30-90 seconds
    • Maximum: 3 minutes (exceptions)

    Website/Platform:
    ─────────────────────────────────────────────────────────────────────────
    • Inline: 1-5 minutes
    • Dedicated page: No strict limit
    • Auto-play: 30 seconds max
    • Background: As needed

    ─────────────────────────────────────────────────────────────────────────

    ENGAGEMENT OPTIMIZATION
    ─────────────────────────────────────────────────────────────────────────

    The First 30 Seconds:
    ─────────────────────────────────────────────────────────────────────────
    • Hook viewer immediately
    • State the value proposition
    • Show compelling preview
    • Avoid introductions

    The Middle:
    ─────────────────────────────────────────────────────────────────────────
    • Deliver on the promise
    • Pacing: vary shot types
    • Re-engage every 2-3 minutes
    • Include chapter markers (if >8 min)

    The End:
    ─────────────────────────────────────────────────────────────────────────
    • Clear call-to-action
    • Preview related content
    • Encourage engagement (like, subscribe)
    • End on key takeaway

    ─────────────────────────────────────────────────────────────────────────

    ATTENTION PATTERNS
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Time          │ Viewer Retention    │ Strategy                    │
    │   ─────────────┼────────────────────┼───────────────────────────── │
    │   0-10 sec    │ 80-90%             │ Hook here                    │
    │   10-30 sec   │ 60-80%             │ Core promise                 │
    │   30-60 sec   │ 50-70%             │ First value delivery         │
    │   1-2 min     │ 40-60%             │ Sustained engagement         │
    │   2-5 min     │ 30-50%             │ Deep content                 │
    │   5-10 min    │ 25-40%             │ Dedicated viewers            │
    │   10+ min     │ 20-30%             │ Committed audience          │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘
```

## 4. Resolution Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         RESOLUTION STANDARDS                                │
└─────────────────────────────────────────────────────────────────────────────┘

    RESOLUTION TIERS
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Resolution   │ Dimensions      │ Use Case                           │
    │   ─────────────┼─────────────────┼─────────────────────────────────── │
    │   4K           │ 3840×2160      │ Production master, future-proofing │
    │   1080p        │ 1920×1080      │ Standard delivery, preferred       │
    │   720p         │ 1280×720       │ Mobile, backup, legacy support     │
    │   480p         │ 854×480        │ Fallback, slow connections         │
    │   360p         │ 640×360        │ Minimum fallback                  │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    DELIVERY SPECIFICATIONS
    ─────────────────────────────────────────────────────────────────────────

    Master File (Archive):
    ─────────────────────────────────────────────────────────────────────────
    • Resolution: 4K (3840×2160) or highest source
    • Codec: ProRes, DNxHD, or high-quality H.264
    • Bitrate: 100-200 Mbps
    • Frame rate: Match source (24/30/60 fps)
    • Color space: Rec. 709 or Rec. 2020

    Primary Delivery (YouTube/Web):
    ─────────────────────────────────────────────────────────────────────────
    • Resolution: 1080p (1920×1080)
    • Codec: H.264 or H.265/HEVC
    • Bitrate: 8-20 Mbps (H.264), 5-12 Mbps (H.265)
    • Frame rate: 30fps standard, 60fps for slow-mo
    • Audio: AAC 320kbps stereo

    Social Media:
    ─────────────────────────────────────────────────────────────────────────
    • Resolution: 1080p preferred, 720p minimum
    • Codec: H.264
    • Bitrate: 4-8 Mbps
    • File size: <1GB per minute preferred
    • Audio: AAC 256kbps

    Mobile Optimized:
    ─────────────────────────────────────────────────────────────────────────
    • Resolution: 720p
    • Codec: H.264
    • Bitrate: 2-4 Mbps
    • File size: <100MB per minute
    • Audio: AAC 128kbps

    ─────────────────────────────────────────────────────────────────────────

    FRAME RATE STANDARDS
    ─────────────────────────────────────────────────────────────────────────

    │   Highlights        │ 60 fps          │ Captures all detail        │
    │   Film look         │ 24 fps          │ Cinematic feel             │
    │   Table overview    │ 30 fps          │ Fixed camera               │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────
```

## 5. Thumbnail Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         THUMBNAIL STANDARDS                                  │
└─────────────────────────────────────────────────────────────────────────────┘

    PURPOSE
    ─────────────────────────────────────────────────────────────────────────
    Thumbnails serve as the visual advertisement for video content, 
    driving click-through rates and setting viewer expectations.

    ─────────────────────────────────────────────────────────────────────────

    DIMENSIONS
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Platform      │ Dimensions (px)   │ Aspect Ratio                  │
    │   ──────────────┼───────────────────┼────────────────────────────── │
    │   YouTube       │ 1280×720         │ 16:9                          │
    │   Vimeo         │ 640×360          │ 16:9                          │
    │   Website       │ 320×180          │ 16:9                          │
    │   Social (FB)   │ 1200×630         │ 1.91:1                        │
    │   Social (IG)   │ 1080×1080        │ 1:1                           │
    │   Social (TikTok)│ 1080×1920       │ 9:16                         │
    │   Twitter/X     │ 1200×675         │ 16:9                          │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    Note: Always produce at 2x resolution for crisp display on retina screens.

    ─────────────────────────────────────────────────────────────────────────

    THUMBNAIL COMPOSITION
    ─────────────────────────────────────────────────────────────────────────

    Rule of Thirds:
    ─────────────────────────────────────────────────────────────────────────
    • Place key subject off-center
    • Use intersection points for emphasis
    • Leave space for text overlay

    Visual Hierarchy:
    ─────────────────────────────────────────────────────────────────────────
    1. Primary focal point (action or expression)
    2. Secondary context (table, equipment)
    3. Text overlay (title, numbers)

    Safe Zones:
    ─────────────────────────────────────────────────────────────────────────
    • Keep critical content in center 80%
    • Avoid placing text in far corners
    • Account for platform UI overlays

    ─────────────────────────────────────────────────────────────────────────

    THUMBNAIL STYLES
    ─────────────────────────────────────────────────────────────────────────

    Style 1: Action Shot
    ─────────────────────────────────────────────────────────────────────────
    • Player in mid-execution
    • Clear view of technique
    • Dynamic pose
    • Background: Table context

    ✓ Example: Player cueing through the ball with 
      dramatic lighting

    Style 2: Result Shot
    ─────────────────────────────────────────────────────────────────────────
    • Dramatic outcome shown
    • Ball in motion or pocketed
    • Emotional reaction (if available)
    • Visual drama

    ✓ Example: Ball dropping into pocket with motion blur

    Style 3: Instructional
    ─────────────────────────────────────────────────────────────────────────
    • Clear demonstration
    • Arrows and annotations
    • Simple composition
    • Educational focus

    ✓ Example: Close-up of bridge formation with 
      numbered steps

    Style 4: Expression/Reaction
    ─────────────────────────────────────────────────────────────────────────
    • Player expression
    • Emotional impact
    • Authentic moment
    • High contrast

    ✓ Example: Professional's concentrated expression 
      before crucial shot

    ─────────────────────────────────────────────────────────────────────────

    TEXT OVERLAY GUIDELINES
    ─────────────────────────────────────────────────────────────────────────

    When to Include Text:
    ─────────────────────────────────────────────────────────────────────────
    • For series branding
    • To clarify complex content
    • For numbered lists/series
    • When face isn't visible

    Text Specifications:
    ─────────────────────────────────────────────────────────────────────────
    • Font: Bold sans-serif (Impact, Bebas Neue, or custom)
    • Size: Minimum 48px at thumbnail size (96px at 2x)
    • Color: High contrast against background
    • Stroke: White or black outline (3-5px)
    • Shadow: Drop shadow for depth
    • Maximum words: 3-5 words

    Recommended Text Treatments:
    ─────────────────────────────────────────────────────────────────────────
    • All caps for impact words
    • Numbers for series (Part 1, Step 3)
    • Question format for curiosity
    • Bold statements that create urgency

    ✗ AVOID in Thumbnails:
    ─────────────────────────────────────────────────────────────────────────
    • Full sentences
    • Small or unreadable text
    • Low contrast colors
    • Cluttered text
    • False claims or clickbait
    • Misleading imagery

    ─────────────────────────────────────────────────────────────────────────

    IMAGE QUALITY
    ─────────────────────────────────────────────────────────────────────────

    Resolution:
    • Minimum: 1280×720
    • Recommended: 2560×1440 (2x for sharpness)

    Format: PNG or JPEG (PNG for transparency)

    File Size:
    • Under 2MB (YouTube limit)
    • Optimized for fast loading

    Colors:
    • Vibrant but not oversaturated
    • Consistent with brand palette
    • High contrast for visibility

    ─────────────────────────────────────────────────────────────────────────

    SERIES/CONSISTENCY
    ─────────────────────────────────────────────────────────────────────────

    For Multi-Part Series:
    ─────────────────────────────────────────────────────────────────────────
    • Consistent template layout
    • Same font and styling
    • Numbering prominent
    • Color coding by level (if applicable)

    Branding Elements:
    ─────────────────────────────────────────────────────────────────────────
    • BKM logo: Small, corner placement
    • Watermark: Optional, 20% opacity
    • Border: Consistent style (optional)

    ─────────────────────────────────────────────────────────────────────────

    PLATFORM-SPECIFIC NOTES
    ─────────────────────────────────────────────────────────────────────────

    YouTube:
    ─────────────────────────────────────────────────────────────────────────
    • Text is essential (most videos auto-play muted)
    • Bright, high-contrast designs
    • Faces perform well
    • Avoid text over faces

    Facebook:
    ─────────────────────────────────────────────────────────────────────────
    • Text on image must be <20% of image
    • Strong visual hook
    • Brand recognition important

    Instagram:
    ─────────────────────────────────────────────────────────────────────────
    • Square or portrait aspect
    • Minimal text
    • Aesthetic consistency
    • High visual quality

    TikTok:
    ─────────────────────────────────────────────────────────────────────────
    • Portrait orientation (9:16)
    • Bold, simple design
    • Large text
    • Matches first frame of video
```

## 6. Title Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           TITLE STANDARDS                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    PURPOSE
    ─────────────────────────────────────────────────────────────────────────
    Video titles communicate content, attract clicks, and optimize 
    for search while remaining accurate and professional.

    ─────────────────────────────────────────────────────────────────────────

    TITLE STRUCTURE
    ─────────────────────────────────────────────────────────────────────────

    Format: {Topic} - {Specific Benefit/Aspect}

    Examples:
    ─────────────────────────────────────────────────────────────────────────
    • "Draw Shot Mastery - The Complete Guide"
    • "Spin Control - 3 Drills to Improve Accuracy"
    • "8-Ball Strategy - Reading the Table Like a Pro"

    Alternative Format: {How-to} + {Specific Technique}

    Examples:
    ─────────────────────────────────────────────────────────────────────────
    • "How to Master the Draw Shot in 5 Steps"
    • "How to Read English on Any Shot"

    Alternative Format: {Curiosity/Question} + {Promise}

    Examples:
    ─────────────────────────────────────────────────────────────────────────
    • "Why Your Break Sucks (And How to Fix It)"
    • "What's the Perfect Stance?"

    ─────────────────────────────────────────────────────────────────────────

    TITLE LENGTH
    ─────────────────────────────────────────────────────────────────────────

    Platform Optimal Lengths:
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Platform      │ Optimal    │ Maximum      │ Notes                  │
    │   ─────────────┼────────────┼──────────────┼─────────────────────── │
    │   YouTube       │ 50-60 chars│ 100 chars    │ Full title visible    │
    │   Website       │ 40-50 chars│ 70 chars     │ Truncate with ...     │
    │   Facebook      │ 40-50 chars│ 255 chars    │ Algorithm favor short │
    │   Twitter/X     │ 60-70 chars│ 280 chars    │ Include hashtags      │
    │   LinkedIn      │ 50-60 chars│ No limit     │ Professional tone     │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    TITLE COMPONENTS
    ─────────────────────────────────────────────────────────────────────────

    Required Components:
    ─────────────────────────────────────────────────────────────────────────
    1. Primary Topic (what the video is about)
    2. Value Proposition (what viewer learns/gets)
    3. Specificity (concrete, not vague)

    Optional Components:
    ─────────────────────────────────────────────────────────────────────────
    • Difficulty level indicator
    • Series indicator (Part X)
    • Format indicator (Tutorial, Analysis, etc.)
    • Duration indicator (Quick Guide, etc.)

    ─────────────────────────────────────────────────────────────────────────

    KEYWORD PLACEMENT
    ─────────────────────────────────────────────────────────────────────────

    Primary Keywords:
    ─────────────────────────────────────────────────────────────────────────
    • Place important keywords near the beginning
    • Front-load value
    • Search engines weight early words higher

    ✓ CORRECT
    "Draw Shot Technique - Master Backspin Control"

    ✗ INCORRECT
    "Master Backspin Control with the Draw Shot Technique"

    Secondary Keywords:
    ─────────────────────────────────────────────────────────────────────────
    • Include naturally in middle/end
    • Don't force for keyword stuffing
    • Maintain readability

    ─────────────────────────────────────────────────────────────────────────

    TITLE FORMATTING
    ─────────────────────────────────────────────────────────────────────────

    Capitalization:
    ─────────────────────────────────────────────────────────────────────────
    Title Case: "Draw Shot Technique - Master Backspin"

    Sentence Case: "Draw shot technique - master backspin"

    Preference: Title Case for consistency

    Punctuation:
    ─────────────────────────────────────────────────────────────────────────
    • Use colon (:) to separate topic from benefit
    • Use dash (-) to separate segments
    • Avoid excessive punctuation (!!!, ???)
    • No period at end

    ✓ CORRECT
    "Draw Shot: The Complete Guide to Backspin"

    ✗ INCORRECT
    "Draw Shot!!! The Best Guide To Backspin????"

    Numbers:
    ─────────────────────────────────────────────────────────────────────────
    • Spell out one through nine
    • Use numerals for 10 and above
    • Use numerals for measurements (5-inch, 30-degree)

    ✓ CORRECT
    "3 Drills to Improve Your Break"

    ✗ INCORRECT
    "Three drills to improve your break"

    ─────────────────────────────────────────────────────────────────────────

    AVOID IN TITLES
    ─────────────────────────────────────────────────────────────────────────

    ✗ Clickbait and False Claims
    "The ONLY Draw Shot Video You'll Ever Need" (subjective)
    "This Trick Will Triple Your Accuracy" (unsubstantiated)

    ✗ Misleading Information
    "Easy" for expert-level content
    "Beginner" for advanced techniques

    ✗ Excessive Hype
    "INCREDIBLE", "AMAZING", "UNBELIEVABLE"

    ✗ Controversy for Clicks
    "Why Pros Are WRONG About..."

    ✗ Incomplete Information
    "How to..." without stating the technique

    ─────────────────────────────────────────────────────────────────────────

    SERIES TITLE PATTERNS
    ─────────────────────────────────────────────────────────────────────────

    Numbered Series:
    ─────────────────────────────────────────────────────────────────────────
    "{Topic} - Part {N}: {Specific}"
    Example: "Stance Fundamentals - Part 1: Foot Positioning"

    Sequential Series:
    ─────────────────────────────────────────────────────────────────────────
    "{Topic} {Level} Series - {Episode N}"
    Example: "Spin Control Beginner Series - Episode 3"

    Challenge Series:
    ─────────────────────────────────────────────────────────────────────────
    "{Challenge Name} - Day {N}"
    Example: "30-Day Practice Challenge - Day 15"

    ─────────────────────────────────────────────────────────────────────────

    LOCALIZATION
    ─────────────────────────────────────────────────────────────────────────

    When translating titles:
    ─────────────────────────────────────────────────────────────────────────
    • Keep primary keywords in original language if stronger
    • Maintain search intent meaning
    • Adapt to local search patterns
    • Consider character limits in target language

    Vietnamese Title Adaptations:
    ─────────────────────────────────────────────────────────────────────────
    • Keep English terms for established billiards vocabulary
    • Translate descriptive elements
    • Maintain keyword research for local SEO
```

## 7. Description Standards

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         DESCRIPTION STANDARDS                                │
└─────────────────────────────────────────────────────────────────────────────┘

    PURPOSE
    ─────────────────────────────────────────────────────────────────────────
    Video descriptions provide context, improve searchability, 
    enable navigation, and drive engagement through calls-to-action.

    ─────────────────────────────────────────────────────────────────────────

    DESCRIPTION STRUCTURE
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Section                  │ Length        │ Purpose                │
    │   ────────────────────────┼───────────────┼──────────────────────── │
    │   Hook (Line 1-2)         │ 1-2 lines     │ Capture interest       │
    │   Summary                 │ 2-4 lines     │ Core content overview  │
    │   Timestamps              │ As needed     │ Navigation aid         │
    │   Links                   │ As needed     │ Resources/CTA          │
    │   Additional Info         │ 2-3 lines     │ Secondary details      │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    ─────────────────────────────────────────────────────────────────────────

    SECTION-BY-SECTION GUIDE
    ─────────────────────────────────────────────────────────────────────────

    1. HOOK (First 1-2 Lines)
    ─────────────────────────────────────────────────────────────────────────
    The first 1-2 lines appear before "Show More" - make them count.

    ✓ CORRECT
    "Learn the draw shot technique that top pros use to 
    control position. This step-by-step guide covers 
    everything from grip to follow-through."

    ✗ INCORRECT
    "In this video I talk about draw shots and some 
    other stuff related to billiards. Thanks for watching."

    Key Points for Hook:
    ─────────────────────────────────────────────────────────────────────────
    • Lead with the main benefit
    • Include primary keyword
    • Make it scannable
    • Create curiosity gap

    ─────────────────────────────────────────────────────────────────────────

    2. CONTENT SUMMARY (2-4 Lines)
    ─────────────────────────────────────────────────────────────────────────
    Expand on the hook with concrete details.

    Template:
    ─────────────────────────────────────────────────────────────────────────
    In this video, you'll learn:
    • [Specific point 1]
    • [Specific point 2]
    • [Specific point 3]

    Key topics covered:
    • [Topic A]
    • [Topic B]

    Example:
    ─────────────────────────────────────────────────────────────────────────
    In this video, you'll learn:
    • The 4 key elements of proper draw shot execution
    • How to diagnose and fix common mistakes
    • 3 practice drills to build muscle memory

    ─────────────────────────────────────────────────────────────────────────

    3. TIMESTAMPS (For videos >3 minutes)
    ─────────────────────────────────────────────────────────────────────────

    Format:
    ─────────────────────────────────────────────────────────────────────────
    ⏱️ TIMESTAMPS
    0:00 - Introduction
    0:30 - What is a draw shot?
    1:15 - Grip technique
    2:30 - Bridge formation
    4:00 - Common mistakes
    5:30 - Practice drill
    7:00 - Conclusion

    Best Practices:
    ─────────────────────────────────────────────────────────────────────────
    • Start at 0:00
    • Round to nearest 15-30 seconds
    • Key moments highlighted
    • Use emoji for visibility (⏱️ or ⏰)
    • Match video exactly

    ─────────────────────────────────────────────────────────────────────────

    4. LINKS & RESOURCES
    ─────────────────────────────────────────────────────────────────────────

    Link Types:
    ─────────────────────────────────────────────────────────────────────────
    • Related videos (playlist)
    • Social media profiles
    • Website/resources
    • Affiliate products (if applicable)

    Format:
    ─────────────────────────────────────────────────────────────────────────
    📚 RESOURCES
    Related Video: [Title] [URL]
    Practice Guide: [URL]
    Equipment Guide: [URL]

    📱 CONNECT
    Instagram: @bkm_official
    Website: www.bkm.com

    Note: Some platforms require "http://" or "https://"

    ─────────────────────────────────────────────────────────────────────────

    5. CALL TO ACTION
    ─────────────────────────────────────────────────────────────────────────

    Recommended CTAs:
    ─────────────────────────────────────────────────────────────────────────
    • "Subscribe for new tutorials every [day/week]"
    • "Like if you found this helpful"
    • "Comment below with your questions"
    • "Share with a friend who wants to improve"
    • "Watch next: [Related video title]"

    Placement:
    ─────────────────────────────────────────────────────────────────────────
    • One CTA at the end
    • Natural, not pushy
    • Specific to content

    Example:
    ─────────────────────────────────────────────────────────────────────────
    If you found this tutorial helpful, give it a thumbs up 
    and subscribe for new training videos every Tuesday!

    ─────────────────────────────────────────────────────────────────────────

    DESCRIPTION LENGTH
    ─────────────────────────────────────────────────────────────────────────

    Platform Guidelines:
    ─────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                      │
    │   Platform      │ Recommended   │ Maximum    │ Note                  │
    │   ─────────────┼───────────────┼────────────┼─────────────────────── │
    │   YouTube       │ 200-500 chars│ 5,000 chars│ First 150 chars visible│
    │   Vimeo         │ 500-1000 chars│ No limit  │ Full description shown │
    │   Website       │ 300-600 chars│ No limit  │ Based on layout        │
    │   Facebook      │ 100-300 chars│ No limit  │ Algorithm favors short │
    │   Twitter/X     │ N/A          │ 280 chars  │ Use for reply/sharing  │
    │                                                                      │
    └─────────────────────────────────────────────────────────────────────┘

    YouTube First Lines Strategy:
    ─────────────────────────────────────────────────────────────────────────
    • First 150 characters visible before "Show More"
    • Pack key info here
    • Primary keyword here
    • Hook here

    ─────────────────────────────────────────────────────────────────────────

    KEYWORD INTEGRATION
    ─────────────────────────────────────────────────────────────────────────

    Where to Include Keywords:
    ─────────────────────────────────────────────────────────────────────────
    • Title (already determined)
    • First 2-3 lines of description
    • Timestamps section
    • Naturally throughout

    Keyword Density:
    • Include primary keyword 2-3 times
    • Include secondary keywords 1-2 times
    • Avoid keyword stuffing
    • Focus on natural language

    ─────────────────────────────────────────────────────────────────────────

    FORMATTING STANDARDS
    ─────────────────────────────────────────────────────────────────────────

    Line Breaks:
    • Use for readability
    • Break up sections visually
    • Don't create walls of text

    Emoji Usage:
    • Optional but helpful for sections
    • Use sparingly
    • Platform-appropriate

    ✓ CORRECT
    ⏱️ TIMESTAMPS
    0:00 - Introduction
    0:30 - Core technique

    ✗ EXCESSIVE
    🚨🔥💯 TIMESTAMPS 💯🔥🚨
    ⭐0:00⭐ Introduction ⭐

    Character Limits in Emoji:
    • Emojis count as characters
    • Consider mobile display
    • Some platforms truncate

    ─────────────────────────────────────────────────────────────────────────

    PLATFORM-SPECIFIC NOTES
    ─────────────────────────────────────────────────────────────────────────

    YouTube:
    ─────────────────────────────────────────────────────────────────────────
    • First 150 characters are crucial
    • Include hashtags (max 15)
    • Update description if content changes
    • Enable auto-generated chapters

    Facebook:
    ─────────────────────────────────────────────────────────────────────────
    • Shorter is better
    • First line most important
    • Include call to action
    • Consider link preview

    Website:
    ─────────────────────────────────────────────────────────────────────────
    • Match website styling
    • Can be longer
    • Include structured data
    • Match meta description
```
