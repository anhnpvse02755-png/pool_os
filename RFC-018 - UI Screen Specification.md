# RFC-018 - UI Screen Specification

Version: 1.0

Status: REQUIRED

Priority: P0

---

# Objective

Every screen must have a fixed layout.

Cursor MUST NOT design screens by itself.

Every screen must follow this specification.

Support Pull To Refresh.

Supports Search.

Supports Tap.

Supports Validation.

# Vietnamese

All text

must support Vietnamese.

No hardcoded English.

---

# Acceptance Criteria

Every screen has a fixed layout.

Every page has loading state.

Every page has empty state.

Every page has error state.

Navigation is consistent across the application.
