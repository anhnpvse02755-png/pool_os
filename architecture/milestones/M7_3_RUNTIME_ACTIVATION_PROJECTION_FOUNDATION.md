**Status:** Accepted; Closed
**Date:** 2026-07-22

Adds an immutable deterministic activation projection from M7.2 dispatch. It
describes activation identity, order, and provenance only; it does not activate
runtime, execute pipelines, transition lifecycle, persist, schedule, or mutate.
